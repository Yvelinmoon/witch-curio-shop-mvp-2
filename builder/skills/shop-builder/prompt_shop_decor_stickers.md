Generate a shop decoration sticker sheet for a customizable world shop game.

Use this prompt as the base template. The user may replace or extend it.

Create 6 large decorative shop props that can be placed around a merge workbench.
The props should strongly match the shop theme, world context, and business fantasy.
They should feel like physical decorations inside the shop: shelves, signs, counters,
display cases, doors, lamps, crates, cabinets, wall props, floor props, or themed ornaments.

Requirements:
- one 2x3 sticker sheet on pure white background
- six separate decorations, one centered object per cell
- generous pure white padding around every object
- clear whitespace between neighboring objects so slicing is safe
- blank surfaces instead of readable writing, signs, logos, labels, letters, or numbers
- isolated props without frames, borders, or dividing lines
- warm handcrafted casual game sticker style
- isolated objects only, no full room scene
- every object should be visually distinct and useful as a draggable shop decoration
