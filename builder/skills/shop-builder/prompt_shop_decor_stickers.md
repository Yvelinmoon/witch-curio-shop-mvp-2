Generate a shop decoration sticker sheet for a customizable world shop game.

Use this prompt as the base template. The user may replace or extend it.

Create 6 decorative shop props that can be placed around a merge workbench.
The props should strongly match the shop theme, world context, and business experience.
They should feel like physical decorations inside the shop: shelves, signs, counters,
display cases, doors, lamps, crates, cabinets, wall props, floor props, or themed ornaments.

Requirements:
- one strict 2 rows x 3 columns sprite sheet on pure white background
- invisible grid layout only: no drawn grid lines, no borders, no dividers
- six separate decorations, exactly one centered object per cell
- all six objects should use a similar scale, similar camera angle, and similar rendering quality
- every object should be centered in its own invisible cell and slightly smaller than the cell bounds
- generous pure white padding on all sides of every object
- clear white gutters between neighboring objects so slicing is safe
- no object should touch, overlap, cast a shadow into, or visually connect with another cell
- blank surfaces instead of readable writing, signs, logos, labels, letters, or numbers
- isolated props without frames, borders, dividing lines, UI panels, speech bubbles, or full room background
- do not scatter objects organically; do not make a poster, collage, shelf scene, storefront scene, or interior scene
- use a clean asset sheet composition like a merge-game item sheet
- warm handcrafted casual game sticker style
- every object should be visually distinct and useful as a draggable shop decoration
